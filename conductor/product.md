# Product Definition

## Project Name
research

## Description
An autonomous research and engineering agent framework designed to conduct deep, systematic, and deterministic investigations. The framework applies deductive sequential thinking ("Macro to Micro"), creates dedicated task workspaces (`[ID]-[Date]-[Name]`), isolates raw records into independent SQLite databases, and enforces deterministic depth limits (such as a 100-source verification floor). It provides dynamic scoping interviews before execution and delivers comprehensive Markdown reports and interactive HTML dashboards upon completion.

## Problem Statement
Human researchers expend excessive time and struggle to maintain systematic consistency and deterministic verification depth across large-scale technical research tasks.

## Target Users
Data analysts, strategy specialists, and software/systems engineers.
